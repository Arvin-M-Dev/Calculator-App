### ✨ Features

- ✅ Basic arithmetic operations (+, -, *, /)
- ✅ Three beautiful theme styles
- ✅ Theme toggle functionality
- ✅ Real-time calculation display
- ✅ Clear (C) and Delete (DEL) buttons
- ✅ Reset button to clear all
- ✅ Error handling for invalid operations
- ✅ Keyboard support for calculations
- ✅ Decimal number support
- ✅ Responsive design (Mobile, Tablet, Desktop)
- ✅ Smooth transitions and animations
- ✅ Modern UI with professional styling

---

### 🛠️ Tech Stack

- HTML5 Semantic
- CSS3 (Custom Properties, Tailwindcss v4, Themes)
- Vanilla JavaScript (ES6+)
- CSS Variables for theme switching
- GitHub Pages for Deployment

---

### 🎯 Key Implementation

**Theme System:**
- Three distinct color schemes (Light, Dark, Purple)
- CSS Custom Properties for dynamic theming
- Persistent theme selection using localStorage
- Smooth color transitions between themes
- Button toggle for easy theme switching

**Calculator Logic:**
- Parse and evaluate mathematical expressions
- Support for decimal calculations
- Operator precedence handling
- Error handling for invalid operations
- Real-time display updates

**User Interface:**
- Large, easy-to-click buttons
- Clear display screen
- Organized button layout (0-9, operators)
- Delete (DEL) button for backspace
- Clear (C) button to reset expression
- Professional typography
